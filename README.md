# CSAI 2026 Paper 129 supplementary appendix

Supplementary appendix for **Investigating the Relationship Between AI-Based Structure Prediction Confidence and Experimentally Determined Protein Stability**.

Authors: Ningquan Zhang, Chen Tang, Hui Lin and Billy Li.

## Read the appendix

[Download or read the supplementary appendix (PDF)](supplement/CSAI129_Supplementary_Information.pdf)

The appendix is self-contained. It includes:

- The 20-protein inventory and 200 experimental mutation labels with source identifiers.
- Local/global association summaries and fixed sequence-baseline comparisons.
- Recorded execution-cost summaries and the limitations of cross-model timing comparisons.
- A per-protein Pearson forest with approximate 95% intervals and all 60 local scatter panels.
- Methods, software provenance and references needed to interpret those supplementary results.

## Scope of this release

This release contains only the publication appendix and this explanatory README. It does not include raw prediction outputs, intermediate processing files, source scripts or separate machine-readable data exports. The main manuscript and reviewer correspondence are not included.

The scientific results and their limitations are unchanged. The analyses are exploratory confidence–stability associations on 200 mutations from 20 selected proteins. They do not establish calibrated energy prediction, a decisive model ranking or a controlled inference-speed benchmark.

The experimental-label table is reproduced with source attribution to Pak et al., Supplementary Table S1 (https://doi.org/10.1371/journal.pone.0282689), derived from ThermoMutDB (https://doi.org/10.1093/nar/gkaa925). Upstream material retains its original rights; this repository does not grant a new license to third-party material.
